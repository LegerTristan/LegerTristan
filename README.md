# Welcome to my profile ! 👋

Hi, I'm Tristan, currently an **AI Developer at DeepGreen Labs** exploring new ways to integrate AIs into games and enhance full game experiences. Right now, I'm working on a new unannounced game project.   
Outside of my job, I'm mostly learning new things from various subjects, currently I'm studying the French Sign Language.

## Latest open-source projects :

- **[InfiniteDungeon](https://github.com/LegerTristan/InfiniteDungeon-OpenSource)** : A proof-of-concept mobile game exploring local LLM inference on Android. Powered by llama.cpp and Unity, this project implements a fully offline, multi-agent narrative system to drive gameplay mechanics (survival, resource management, and event resolution) directly on-device.
- **[ValuableSoundTrigger](https://github.com/LegerTristan/RepoMod-ValuableSoundTrigger)** : A mod for R.E.P.O introducing controled audio triggers for valuable objects. Built to prank your friends with fake damage sound on valuables or simply to play Tralalero Tralala from SillyValuables mod, as you wish.
